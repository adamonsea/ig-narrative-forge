# Route rules
- Feed/story link previews come only from route `loader`+`head()` via `src/lib/shareMeta.ts`; crawlers read the server HTML, never client code.
- Public feed address is `/@{slug}`: `src/router.tsx` rewrites it to the unchanged `/feed/$slug/...` routes (`src/lib/feedHandle.ts`); renamed handles redirect via `topic_slug_history` (`resolve_feed_slug`, set only through guarded `set_feed_handle`); one route tree, old links work forever.
- The public feed's first screen (topic rows, insight settings, stories page, popularity, metadata, first events page for individual-event feeds) comes from the route loader via `src/lib/feedFirstScreen.ts` and seeds the feed hook and query cache for start-up only, with a first-picture preload in head(); card 1 needs no client round trips. Reader-only code (e.g. `useFeedEvents`) never imports workspace modules, and pop-ups load on demand; keeps the reader download small.
