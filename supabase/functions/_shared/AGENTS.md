- AI pictures are drawn automatically only once a story is live (`needsPublishIllustration` in `supabase/functions/_shared/illustration-gate.ts`, used by the writer, drip publisher and Desk Publish); drafts never cost credits. Owner "no picture" choices (`stories.skip_auto_illustration`, Autopilot pictures off via `feedAllowsAutoPictures`) are enforced inside `story-illustrator` for every automated call, so no path can bypass them.
- Story pinning: up to 9 live stories pinned at once on `stories.pinned_at`/`pinned_until`, set only via guarded `set_story_pin` (24/48/168h; hours 0 unpins that story) and listed publicly via `get_topic_pinned_stories` (fan deck above the feed); `set_story_pin` mirrors the most recent pin into `topics.pinned_story_id` so feed RPCs, emails and `storyPin.ts` rules keep one leading story with no clean-up job.
- Publisher names only in `publisherNames.ts`; site address/sender only in `brandConfig.ts` (email, RSS, widget, push); modules never hard-code brand or tenant values, so they stay liftable.
- Website widgets pick news, events or both only via `resolveWidgetContent` and look (`data-style` list = headlines with News | What's on tabs, cards = swipeable feed-style cards, both = one row ordered by `mixWidgetCards`) only via `_shared/widgetContent.ts` (auto = events-led feeds show events, others keep news; events only when shown in the feed); builders preview through `LiveWidgetPreview` running the real `widget.js` (`data-preview` = not counted), so preview, embed and tests never drift.
- RSS enclosures carry only Curatr illustrations (`illustration_generated_at` set, our storage, not `publisher-N`); uncredited source photos never leave via RSS.
